# OctoAcme Project Management Docs

Welcome to the OctoAcme Project Management documentation hub. This README serves as a central index and introduction to all process documentation for the OctoAcme team.

## Overview

OctoAcme follows a structured, collaborative approach to project management guided by five core principles:

- **Customer-first**: Prioritize customer value and usability in every decision.
- **Iterative delivery**: Deliver small, testable increments to reduce risk and gather feedback early.
- **Clear ownership**: Each project has a named Project Manager (PM) and Product Lead responsible for outcomes.
- **Data-informed decisions**: Measure impact and iterate based on evidence rather than assumptions.
- **Psychological safety**: Encourage open feedback, experimentation, and learning from failure.
